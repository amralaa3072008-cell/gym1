DEALPILOT — طريقة التشغيل على Windows
======================================

1) فك ضغط DEALPILOT.zip في مجلد عادي على الكمبيوتر.
2) نزّل Node.js LTS من https://nodejs.org إذا لم يكن موجودًا.
3) افتح مجلد dealpilot في Visual Studio Code: File > Open Folder.
4) من القائمة Terminal > New Terminal.
5) اكتب الأمرين التاليين، كل أمر ثم Enter:

   npm install
   npm run dev

6) افتح الرابط الذي يظهر في التيرمنال، غالبًا:
   http://localhost:5173

طريقة أسهل:
- بعد تثبيت Node.js وفك الضغط، افتح مجلد dealpilot واضغط مرتين على start-windows.bat.

ماذا يعمل الآن؟
- لوحة تحكم عربية/إنجليزية بتصميم داكن متحرك.
- إضافة وتعديل وحذف العملاء وتغيير مرحلة البيع.
- صفحة تجربة للنادي مع رابط ورمز QR، وطلبات التسجيل تظهر كعملاء محتملين على هذا المتصفح.
- كود وباركود فريد لكل عضو، مع تسجيل الزيارات من شاشة الحضور بالكتابة أو قارئ الباركود.
- مسار مبيعات بالسحب والإفلات.
- إضافة مهام ومتابعات ووضع علامة الإنجاز.
- البحث والتصفية واستيراد Excel/CSV وتصدير Excel.
- تقارير ورسوم بيانية وفريق تجريبي.
- شاشة باقات Free / Pro / Business تجريبية دون تحصيل أموال.
- مساعد رسائل يستخدم قالبًا محليًا، ويمكنه تجربة Ollama إذا أعددته.
